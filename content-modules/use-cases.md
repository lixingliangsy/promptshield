# PromptShield — Use Cases

### Customer chatbots
- **Pain:** Untrusted users try ignore-previous-instructions attacks.
- **How PromptShield helps:** Scan description + sample input; get pattern hits and hardening steps.
### RAG apps
- **Pain:** Retrieved docs carry indirect injection.
- **How PromptShield helps:** Flag delimiter break-out and goal-hijack patterns.
### CI for AI apps
- **Pain:** Need a pre-merge gate.
- **How PromptShield helps:** Pro: CI-oriented runs with audit log.
### Security reviews
- **Pain:** Need an explainable pattern checklist.
- **How PromptShield helps:** Deterministic rules fire before the model.
